# Istruzioni per Claude Code

## Merge automatico

Quando completi delle modifiche su un branch di lavoro per questa repo e l'utente
chiede (anche implicitamente, proseguendo la conversazione) di pubblicarle,
crea la pull request verso `main` e mergiala direttamente, senza chiedere
conferma preventiva. Questa è una regola durevole, richiesta esplicitamente
dall'utente il 2026-08-03: non serve ridomandare "vuoi che merge?" prima di
ogni merge.

Resta comunque valido il buon senso generale: se una modifica è ambigua,
rischiosa o va oltre quanto richiesto, chiedi prima di procedere.
